Sincronização e Conexão com ODK Collect (Android) Ativo

Este construtor de formulários compila os modelos de perguntas diretamente no padrão internacional XForms XML. Os pesquisadores de campo freelancer podem usar o aplicativo oficial do ODK Collect no Android para realizar as entrevistas offline no interior e enviar as respostas e gravações de áudio de volta ao nosso servidor.

Passo 1: Instale o App Baixe o app ODK Collect gratuitamente na Google Play Store no celular do pesquisador.
Passo 2: Configure o Servidor No ODK Collect, vá nas configurações do projeto, selecione Configuração Manual e insira os dados:
• URL do Servidor: http://localhost:3000/api
Passo 3: Baixe e Sincronize O app carregará os formulários publicados. As respostas enviadas aparecerão automaticamente no nosso Mapa de Campo acima!

Console de Rede - Gestão de Equipamentos de Campo

Este módulo simula a interação técnica com os roteadores e portais de sincronização das bases remotas. De acordo com as regras operacionais, os módulos operam estritamente em modo READ-ONLY. Qualquer comando destrutivo inserido por operadores humanos será interceptado, bloqueado, gerará um alerta e será registrado no log de auditoria.

router-sync-node01.antigravity.corp
Antigravity Safe Network Controller v1.4.2-RO
Sistema conectado em modo READ-ONLY. Equipamento ativo.
Digite 'help' para listar os comandos.
Coordinator@node01:~$

Manual de Comandos

Comandos Seguros (Read-Only):

  • show version - Exibe a versão do firmware.
  • ping 8.8.8.8 - Testa conexão externa.
  • /ip address print - Imprime os endereços IPv4 configurados.
  • show status - Exibe estatísticas de latência de sincronização.

Comandos Destrutivos Bloqueados (Auditados):

  • reboot - Força reinicialização do dispositivo.
  • reset - Apaga configurações.
  • /system reset - Restaura padrões de fábrica.
  • /interface disable ether1 - Desativa a interface WAN.
  • /ip route remove [id] - Remove uma rota ativa.
